Merge duplicate names in

The same person ends up as two rows when one import writes Last, First and another First Last, or a name is misspelled. Merging moves every entry onto the row you keep and deletes the other (the kept row wins where both have the same day). Likely pairs are listed; any two rows can be merged by hand.
